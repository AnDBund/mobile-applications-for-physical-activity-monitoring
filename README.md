Комп'ютерна програма «Мобільні додатки для моніторингу рухової діяльності»
Computer program "Mobile applications for physical activity monitoring"

Опис та призначення твору:
Інтерактивний програмно-методичний засіб (вебдодаток) створено для забезпечення навчального процесу та мікронавчання студентів спеціальності А7 Фізична культура і спорт (галузь знань Освіта). Програма реалізує систему подачі дидактичного матеріалу, практичних завдань і алгоритмів аналізу даних рухової активності з використанням сучасних мобільних додатків і цифрових сенсорів.

Project Description:
An interactive educational web application designed for microlearning in higher education, specifically tailored for students majoring in Physical Education and Sport. The software provides structured educational modules, self-assessment tasks, and methodologies for physical activity monitoring, biomechanical evaluation, and data tracking.

Технічні характеристики:

Тип твору: комп'ютерна програма (вебдодаток)

Мови розмітки та сценаріїв: HTML5, CSS3, JavaScript

Середовище проектування: прототипування засобами Google AI Studio

Системні вимоги: будь-який сучасний веббраузер для персональних комп'ютерів або мобільних пристроїв
